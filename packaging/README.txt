EverDefault - 守住你的默认设置
================================

它做什么
--------
EverDefault 会守住你选择的默认程序和系统设置。被其他软件改动时，
它会自动改回来，并在托盘弹出提示。

怎么用
------
1. 双击 EverDefault.App.exe。
2. 首次启动会弹出向导：勾选想保护的项目，点“开始保护”。
3. 完成。以后其他程序想改这些设置时会被自动改回。

不需要了解注册表、ProgId 或哈希算法。

界面
----
- 主页：保护状态、暂停/恢复、统计、推荐保护、最近活动。
- 我的保护：按应用聚合的保护项，每项一个开关，可调整/暂停/停止。
- 活动：普通语言的拦截记录，可展开原始详情。
- 设置：常规设置；服务模式、用户范围等收在“高级选项”。
- 高级规则：在 设置 → 高级选项 中打开“显示高级选项”后出现。

基础配置 / 高级配置
-------------------
添加保护时有两个 Tab：
- 基础配置：搜索、勾选、图形化预览，适合大多数情况。
- 高级配置：填写原始注册表信息，适合需要精确控制的用户。

通知与暂停
----------
- 拦截时托盘气泡会提示，例如：“检测到「.pdf 默认程序」被修改，已改回 Acrobat。”
- 点击气泡可打开对应规则调整。
- 托盘右键可“暂停保护 1 小时”；设置里可完全关闭通知。

组件
----
- EverDefault.Service.exe   后台监控引擎（支持系统级与各用户设置）
- EverDefault.App.exe       托盘 + 图形界面（通过命名管道连接服务）

正式安装为开机自启服务（需要管理员）
------------------------------------
1. 右键 install-service.cmd -> 以管理员身份运行。
2. 运行 EverDefault.App.exe，它会自动连接服务。
   需要开机自启可在“设置”里开启。

卸载
----
- 右键 uninstall-service.cmd -> 以管理员身份运行。
- 用户数据位于 %ProgramData%\EverDefault
  （rules.json / baselines.json / changelog.json / settings.json），可手动删除。

杀毒软件提示
------------
本工具会“监控并回写注册表”，容易被杀毒软件误报为可疑。
请将以下文件加入杀软/防火墙白名单：
- EverDefault.Service.exe
- EverDefault.App.exe
- 数据目录 %ProgramData%\EverDefault

常见问题
--------
想换默认程序，但被改回去了？
  先暂停保护（托盘右键或在“我的保护”里暂停），再改默认程序。

通知太吵？
  设置 → 取消“拦截时用气泡通知我”，后台仍会保护并记录。

已知限制
--------
- 默认应用（UserChoice）哈希算法在 Win10/11 验证通过；Win7/8 走传统关联路径。
- 仅处理已加载的用户配置单元（已注销用户不处理）。
- 通知只提示检测到修改，不显示具体写入进程（注册表通知不携带进程信息）。
- “打开方式(OpenWithProgids)”项以 REG_SZ 空值写入，功能可用但类型与系统不完全一致。
